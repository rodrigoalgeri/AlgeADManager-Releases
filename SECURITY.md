# Segurança e privacidade

## Antes de publicar uma informação

As Issues e demais áreas deste repositório são públicas. Utilize apenas dados fictícios, preferencialmente do ambiente simulado do AlgeAD Manager.

**Não publique:**

- nomes de domínio, endereços IP internos, nomes de controladores, estações ou unidades organizacionais reais;
- credenciais, tokens, senhas temporárias, chaves ou configurações de autenticação;
- dados pessoais ou corporativos, logins, matrículas, e-mails, listas de grupos e permissões reais;
- históricos, exportações, logs brutos, arquivos de configuração ou capturas de tela não anonimizadas.

## Relatos de problemas

Para defeitos não confidenciais, abra uma [Issue pública](https://github.com/rodrigoalgeri/AlgeADManager-Releases/issues) com a versão do aplicativo, a versão do Windows, os passos para reproduzir e o resultado esperado.

Se identificar uma possível vulnerabilidade ou exposição de dados, **não publique os detalhes técnicos nem provas de exploração em uma Issue pública**. Use um canal privado autorizado com o responsável pelo projeto. Nenhum endereço específico de recebimento de vulnerabilidades foi publicado nesta política.

## Instalação e integridade

Baixe os pacotes exclusivamente pela [página oficial de releases](https://github.com/rodrigoalgeri/AlgeADManager-Releases/releases). Confira os hashes SHA-256 fornecidos e as exigências de base de cada atualização. Os instaladores ainda não possuem assinatura Authenticode própria; não desative proteções ou ignore políticas de execução da sua organização.

O canal RC requer homologação antes do uso em produção. Utilize contas, ambientes e operações autorizados. As permissões do Active Directory não são substituídas pelo aplicativo.
